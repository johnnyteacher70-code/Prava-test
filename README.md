# Prava Akademiya

Oson Prava uslubidan ilhomlangan, lekin mustaqil dizayndagi haydovchilik nazariyasi uchun frontend o‘quv loyihasi.

## Ishga tushirish
1. ZIP faylni oching.
2. `prava-akademiya` papkasini VS Code orqali oching.
3. `index.html` faylini brauzerda oching yoki VS Code ichida **Live Server / Go Live** tugmasini bosing.

## Fayllar
- `index.html` — sahifa tuzilishi
- `style.css` — dizayn va moslashuvchan ko‘rinish
- `script.js` — testlar, navigatsiya, profil, statistika va LocalStorage
- `assets/dashboard-reference.png` — dizayn uchun tayyorlangan namuna tasviri (agar ZIP ichida mavjud bo‘lsa)

## Ishlaydigan imkoniyatlar
- Bosh sahifa va bo‘limlar o‘rtasida to‘liq navigatsiya
- **⏱ Imtihon simulyatori**: 20 ta savol, 20 daqiqalik orqaga hisoblovchi taymer, ruxsat etilgan xatolar me'yori (maksimum 2 ta xato)
- **🎨 Vizual yo‘l belgilari**: Savollarda vektorli (SVG) haqiqiy yo‘l belgilari va svetofor signallari tasviri
- 5 ta namuna bilet va 4 ta asosiy mavzu bo‘yicha testlar
- Smart test (tasodifiy 10 savol)
- Xatolar ro‘yxati va xatolar ustida qayta mashq qilish
- To‘g‘ri javob, foizlar, progress halqasi va batafsil statistika
- Ism bilan profil sozlash va LocalStorage orqali natijalarni saqlash
- Savollarni ovozli o‘qish (Web Speech API)
- Qorong‘i / yorug‘ rejim (Dark / Light mode)
- Google Fonts (Plus Jakarta Sans) bilan zamonaviy va toza tipografiya
- Telefon, planshet va kompyuter ekranlariga to‘liq moslashuvchan (Responsive) dizayn

## Muhim eslatma
Bu to‘liq ishlaydigan **frontend demo**, ammo haqiqiy foydalanuvchilar orasidagi onlayn jang, serverga sinxronlash, rasmiy 1264+ savol bazasi, autentifikatsiya va offline PWA hali kiritilmagan. Buning uchun backend, rasmiy ma’lumotlar manbasi va qo‘shimcha sozlash kerak. Savollar namuna uchun tuzilgan; ularni rasmiy imtihon savollari deb qabul qilmang.
